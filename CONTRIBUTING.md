# Contributing to Rhine Solution Website

## Conventions

### RAGNAROK (CEO) Conventions
- Use dark theme as default for personal portfolio sections
- Prefer bold, impactful language in copy
- Prioritize visual storytelling and project showcases

### ZeroMeister (CTO) Conventions
- Use light/theme-neutral as default for technical documentation
- Focus on clarity, precision, and accessibility
- Emphasize clean, minimal design and technical details

### General
- All code must pass linting and type checking
- Commit messages follow conventional commits
- Pull requests require review from both RAGNAROK and ZeroMeister
