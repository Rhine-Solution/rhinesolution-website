# Rhine Solution

Custom web development portfolio and business site.

## Stack
- Next.js 15 (App Router)
- TypeScript
- Pure CSS (no framework)

## Local development
```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deployment
Deployed to Vercel: https://rhinesolution.com
